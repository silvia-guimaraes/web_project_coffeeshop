markdown# Ctrl + Alt + Coffee ☕

Landing page para o café fictício "Triple Espresso", uma cafeteria e espaço de estudo/coworking na biblioteca Triple Peaks.

## Descrição do projeto

Este projeto é uma página de destino (landing page) responsável por apresentar o café, suas receitas favoritas em vídeo, e permitir que os clientes reservem uma mesa através de um formulário de contato.

A página inclui:
- Cabeçalho com menu de navegação e apresentação do espaço
- Seção de receitas com vídeos incorporados via YouTube
- Formulário de reserva de mesa com validação nativa do HTML (campos obrigatórios, tipos de entrada específicos)
- Rodapé com links para redes sociais

### Tecnologias utilizadas

- HTML5 semântico
- CSS3, seguindo a metodologia BEM (Block, Element, Modifier) com estrutura de arquivos BEM Flat
- Flexbox para layout
- Normalize.css para consistência entre navegadores
- Google Fonts (Inter e Noto Serif)

## Planos de melhoria

- Adicionar validação de formulário com JavaScript, com mensagens de erro personalizadas para cada campo.
- Tornar a página responsiva, adaptando o layout para celular e tablet.
